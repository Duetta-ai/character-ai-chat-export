# Privacy policy: Duetta Chat Export

Last updated: November 1, 2026

Duetta Chat Export is a Chrome extension published by Duetta. It saves a character you created on Character.AI, and your chat with it, to a file on your computer.

**In short: the extension does not collect any data. It sends nothing to Duetta or to anyone else. What it reads stays on your computer.**

## What the extension reads

Only after you click its icon, and only in the tab where you clicked it:

- On your character's Edit page: the character's name, tagline, description, greetings and definition, as the form shows them, and the character's id from the page address.
- On your chat page: the messages shown and who wrote each one (you or the character), the character's id and, if the address has it, the chat id. To check that the character is yours, it also compares the creator's username in the chat header with the username of the account you are signed in with. The usernames are not saved.
- A picture, only if you choose an image file yourself.

## What it does with it

- Shows you a preview in the extension's window.
- Keeps the character card and the chat in the browser's session storage (in memory) until you save the file, press **Start over** or close the browser.
- When you press **Save file**, hands the file to the browser, which saves it to your Downloads folder. After that the extension keeps nothing.

## What it does not do

- It makes no network requests: no servers, no analytics, no tracking, no advertising, no code loaded from the internet.
- It does not read other tabs, your browsing history, cookies, passwords or the site's storage.
- It does nothing in the background: there is no background script and no script that runs on pages by itself.
- It does not sell, share or transfer any data, because no data leaves your computer.

The extension uses this data only to make the file you asked for. Its use of the data complies with the [Chrome Web Store User Data Policy](https://developer.chrome.com/docs/webstore/program-policies/policies), including the [Limited Use](https://developer.chrome.com/docs/webstore/program-policies/limited-use) requirements.

## Your file

The saved file is plain, unencrypted JSON, and it is yours. Keep it like any private document. Deleting the file deletes the data. If you choose to import it into another service, such as Duetta, that service's privacy policy applies to it there.

## Changes

If a future version changes how the extension handles data, this policy will be updated before that version is published, and the date above will change.
